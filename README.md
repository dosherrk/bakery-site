# 🥖 Пекарня «Колосок» — учебный проект

Одностраничный адаптивный сайт выпечки на чистом HTML, CSS и JavaScript.

## Демо

После публикации сайт доступен по адресу:
`https://<ваш-логин>.github.io/<название-репозитория>/`

## Что использовано (по заданию)

| Требование | Где применено |
|---|---|
| **Flexbox** | Шапка (`header__inner`), меню, сетка карточек выпечки (`menu__grid`), преимущества, секция «О нас», подвал |
| **Относительные единицы** | Ширины контейнеров в `%`, высота главного экрана `100vh`, отступы секций `vh/vw`, шрифты `clamp()` + `rem`, `aspect-ratio` для картинок |
| **Медиа-запросы** | `@media (max-width: 900px)` — планшет, `@media (max-width: 600px)` — телефон |
| **Мобильная адаптация** | Бургер-меню с выезжающей панелью, перестройка сеток: 4 → 2 → 1 карточка в ряд, картинка «О нас» переходит из горизонтали в вертикаль |

## Структура проекта

```
bakery-site/
├── index.html        # разметка страницы
├── css/
│   └── style.css     # все стили, flexbox, медиа-запросы
├── js/
│   └── script.js     # мобильное меню и год в подвале
├── images/           # фотографии выпечки
└── README.md
```

## Как открыть локально

Просто откройте `index.html` в браузере — сборка не нужна.

## Публикация на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `bakery`.
2. Загрузите в него **содержимое** папки `bakery-site` (файл `index.html` должен лежать в корне репозитория).
3. Откройте **Settings → Pages**.
4. В разделе *Build and deployment* выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/bakery/`.
